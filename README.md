# Restaurant Branch Performance EDA

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a Restaurant Branch Performance dataset using Python. The analysis explores restaurant performance, customer activity, financial metrics, operational factors, and relationships between numerical variables.

The main objective is to identify meaningful patterns and generate data-driven insights from the dataset.

## 🎯 Objectives

* Understand the structure and characteristics of the dataset.
* Perform descriptive and summary statistics.
* Analyze distributions of important numerical variables.
* Compare restaurant performance across branches, regions, and store types.
* Study relationships between customers, revenue, profit, marketing spend, staff count, delivery time, and customer ratings.
* Use correlation analysis to identify meaningful relationships between numerical variables.
* Generate key data-driven observations from the analysis.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / VS Code

## 📊 EDA Performed

The notebook includes:

* Dataset loading and inspection
* Data structure and data type analysis
* Missing-value analysis
* Descriptive statistics
* Distribution analysis
* Boxplot and outlier analysis
* Branch-wise performance comparison
* Region-wise performance comparison
* Store-type comparison
* Customers vs Revenue analysis
* Marketing Spend vs Revenue analysis
* Delivery Time vs Customer Rating analysis
* Promotion analysis
* Correlation matrix
* Correlation heatmap
* Key data-driven observations

## 🔍 Key Insights

* Restaurant performance varies across branches and regions.
* Premium stores show substantially higher average revenue compared with Standard and Express stores.
* Customer volume has a strong positive relationship with revenue.
* Staff count is positively associated with customers and revenue.
* Staff count also has a strong relationship with operating costs.
* Marketing spend shows a moderate positive relationship with customers and revenue.
* Customer ratings remain relatively similar across different store types.
* Delivery time has a weak relationship with customer ratings in this dataset.

> **Note:** Correlation indicates an association between variables and does not necessarily imply causation.
